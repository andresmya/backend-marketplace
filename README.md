# Backend Marketplace

This repository contains a personal-demo project in order to refine my developments skills and have a platform to acquire and test new knowledge.

It is a basic backend marketplace application that exposes a Rest API for integrations with any type of client.

This project has a large ToDo tasks list, bug fixes, business logic and new features, this is not a production-commercial application.
